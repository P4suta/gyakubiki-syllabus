# Gyakubiki syllabus

Unofficial timetable browser for Kochi University courses.

## Installation

```sh
# Open https://p4suta.github.io/gyakubiki-syllabus/ in a web browser
```

## Usage

```text
Choose a term, then filter by department or search for a course by name, instructor, or course code.
```
